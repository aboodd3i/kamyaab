# Kamyaab Product Documents

This directory contains the five core product and engineering documents for the
Kamyaab platform. They are listed below in implementation-priority order.

## Documents

### 1. Backend Roadmap — `Kamyaab_Backend_Roadmap_Updated (1).pdf`

**Primary source for current backend scope and delivery order.**

Defines the backend implementation roadmap, including week-by-week delivery
milestones, API surface areas, and the sequencing of features across the
MVP lifecycle. This is the authoritative document for what the backend team
should build and when.

### 2. Frontend Roadmap — `Kamyaab_Frontend_Roadmap (1).pdf`

**Source for frontend/backend contracts and delivery dependencies.**

Defines the frontend implementation roadmap and the contracts between the
mobile application and the backend API. Use this document to understand
which backend endpoints the frontend depends on and in what order they
must be delivered.

### 3. Architecture Review — `Kamyaab_Architecture_Review_Draft_v1.pdf`

**Source for domain boundaries, security rules, and architecture principles.**

Covers the system architecture, domain boundaries between services, security
rules, authentication and authorization design, and overarching technical
principles. Consult this document when making decisions about system
structure, data ownership, or security boundaries.

### 4. Product Pitch — `Kamyaab - AI Dot (Straw Hats).pdf`

**Final product pitch and product intent.**

The polished product pitch deck that communicates the vision, target market,
value proposition, and product intent for Kamyaab. Use this for stakeholder
alignment and onboarding context.

### 5. First Draft — `Kamyaab_first draft.pdf`

**Historical product context only where newer documents do not override it.**

The earliest product draft. It provides background and historical context,
but any conflicts with the newer documents above should be resolved in favor
of the more recent versions.
